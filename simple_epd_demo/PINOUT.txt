* RST pin changed from D8 to D6 because D8 (P1.00) is not available
  on nRF52840-preview-DK. Alternative free pins: D5, D4, D3, D2

NOTES:
• Use female-to-female jumper wires for connections
• Double-check VCC is connected to 3.3V (NOT 5V!)
• GND must be connected for proper operation
• Keep wires short (<20cm) for reliable SPI communication
• BUSY pin is used to detect when display is ready

SIGNAL DESCRIPTIONS:
• VCC:  3.3V power supply (typically 3-10mA during refresh)
• GND:  Ground reference
• DIN:  Serial data input (MOSI) - MCU sends data to EPD
• CLK:  Serial clock (SCK) - synchronizes data transfer
• CS:   Chip select (active low) - enables SPI communication
• DC:   Data/Command select (0=Command, 1=Data)
• RST:  Reset (active low) - hardware reset of EPD controller
• BUSY: Busy status output (HIGH during refresh/update)
